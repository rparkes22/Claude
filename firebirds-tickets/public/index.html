How it works
  1. Enter your name for any home games you'd like to attend. Enter as many as you want.
  2. At the beginning of each month, one name is drawn at random for each of that month's games from everyone who entered.
  3. Win once and you're set for the season, so everyone gets a turn.
  4. If you can no longer go to your game, please return the tickets to the pool and you'll have another chance for future games.
